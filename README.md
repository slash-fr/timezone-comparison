# Time Zone Comparison

A small web app to quickly visualize the time in multiple time zones.

> *It's five o'clock somewhere.*

![Animated preview](doc/animated-preview.avif)


## Features

- Responsive layout
- Infinite scrolling
- Handles Daylight Saving Time (Summer Time / Standard Time)
- Configurable time formatting (24-hour clock, or AM/PM)
- Optional highlighted hours (Could be working hours, waking hours, ...)
- Light and dark themes
